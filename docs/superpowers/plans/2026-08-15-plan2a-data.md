# Plan 2a — Data Layer (`data/`): adapters, DuckDB store, derived metrics, `DuckDBDataService`, refresh CLI, snapshot

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the public sources in design 01 into one provenance-tagged DuckDB snapshot, compute every tier A/B metric of the frozen registry into `airport_metrics` (latest value + annual series), expose it only through `DuckDBDataService` (passes the shared contract suite), and ship `python -m airport_agent.data refresh [--check]` plus a committed snapshot ≤100 MB.

**Architecture:** `data/adapters/*` (one file per source; `fetch → normalize → vintage`), `data/store.py` (schema + writes), `data/derived/*` (one function per metric id, parametrized by reference year so the same code yields the latest value and the annual series), `data/service.py` (`DuckDBDataService`), `data/refresh.py` + `__main__.py` (CLI), `data/quality.py` (data-quality notes). Tests: real-but-tiny fixture subsets per source drive a **test snapshot** built at test-session start; the contract suite runs against it via `tests/data/conftest_plugin.py`.

**Tech Stack:** Python 3.12, DuckDB, pandas, pyarrow, httpx, openpyxl, PyYAML, pydantic v2. No new dependencies (report a `DECISION NEEDED` if one seems required).

**Spec:** `docs/design/01-data-layer.md`, `02-metrics-and-scoring.md` (registry semantics), `docs/research/2026-08-15-us-aviation-data-sources.md` (verified URLs/columns), limitations rows 1–8, 10, 14, 19, 21. Frozen: `contracts/{models,data_service,registry}.py`, `config/metrics.yaml`; shared suite `tests/contracts/test_data_service_contract.py` (read it first — it is the acceptance test).

## Global Constraints
- **FROZEN SURFACE:** `src/airport_agent/contracts/**`, `config/metrics.yaml` unchanged. Reviewers git-verify. Need a change → STOP, `DECISION NEEDED`.
- **Ownership:** only `src/airport_agent/data/**`, `config/sources.yaml`, `data/**` (snapshot, curated, raw cache — raw is gitignored), `tests/data/**`, `tests/fixtures/**`, and the repo-root `conftest.py` ONLY to set `pytest_plugins = ["tests.data.conftest_plugin"]`. Never touch scoring/llm/agent/ui, `pyproject.toml`, `tests/fakes.py`, `tests/contracts/**`.
- **Layering:** `data/` imports only `airport_agent.contracts` and itself.
- **No network in the default test run.** Adapter `fetch` is exercised only under `@pytest.mark.network`; `normalize` is tested on committed fixture files (each ≤ 300 KB, real subsets — never hand-invented numbers). The snapshot build (Task 16) is the one networked step, run by the implementer, not by tests.
- **Horizon rule (contract, non-negotiable):** `get_feature_matrix`/`get_profile` return a metric at a horizon only if `MetricSpec.horizons` declares it (static/forecast metrics answer any horizon at their own); never relabel. Multi-year semantics: **CAGR-type metrics = growth over k years; level metrics at horizon k = computed over the trailing k-year window** (12m = trailing 12 months). State this in `service.py` docstring and in `describe`-level caveats where relevant.
- **Provenance:** every `airport_metrics` row and every `Metric` returned carries `source_id` + `vintage` (`YYYY-MM` of the latest period used, or the file's vintage), `period_start`, `period_end`. Every raw table row carries `source_id`, `vintage`.
- **No invented numbers:** an unavailable metric is `None` (with reason where a QualityFlag fits); tier C is never computed; tier B only where curated YAML has the input.
- **Failure handling in refresh:** per-source try/except, snapshot keeps last good, `--check` prints staleness; a failing adapter never aborts the run.
- **Snapshot ≤ 100 MB** committed at `data/snapshot/airports.duckdb`; raw downloads cached under `data/raw/` (gitignored); never commit files > 5 MB except the snapshot.
- Escalation (design 05 §5.0): a source whose format differs from the research note, an unreachable endpoint, a registry metric that cannot be defined honestly, DB1B/Delay-Cause/CATS timebox exhaustion → STOP, `DECISION NEEDED` (finish independent tasks meanwhile).

## Derived metric definitions (Task 13) — `fn(con, ref_year: int, latest_period: str) -> DataFrame[iata, value, period_start, period_end, source_id, vintage, quality_json]`
`ref_year` = calendar year the window ends in (Dec, or `latest_period` for the current year); `latest_period` = latest `YYYY-MM` with Socrata data. Windows: 12m = 12 months ending at the window end; ky = k×12 months. `common.py`: `window_months(horizon, end_period) -> (start_period, end_period)`, `cagr(new, old, k)`, `sum_measure(con, measure, start, end)`, `annual_enplanements(con, year)` (Socrata `total_passengers` summed over the calendar year; if the year is incomplete, use TAF actual if present else trailing 12m — flag `quality: {"code":"partial_year"}`).
| metric_id | source_id | horizons | definition (window per horizon) |
|---|---|---|---|
| enpl_cagr_3y/5y/10y | bts_socrata | 3y/5y/10y | `cagr(E_ref, E_{ref-k}, k)` on annual enplanements; if Socrata lacks `ref-k` use `taf_history` enplanements for that year and flag `source_mix` |
| taf_cagr_10y | faa_taf | forecast | `cagr(TAF_{base+10}, TAF_base, 10)`, base = first forecast year |
| taf_vs_actual_gap | faa_taf,bts_socrata | 12m | `taf_forecast.enplanements[ref] / annual_enplanements(ref)`; if TAF has only history for `ref` use `taf_history` (then flag `taf_actual`) |
| load_factor | bts_socrata | 12m,3y,5y,10y | Σpassengers / Σseats over the window (`airport_month` measures `total_passengers`,`total_seats`) |
| spill_proxy | bts_t100 | 12m,3y | per (dest, carrier) with ≥6 months in window and seats>0: LF_m = pax/seats; CV = std/mean; airport = departure-weighted mean CV |
| seats_per_dep_trend | bts_socrata | 5y | `(seats/dep)_ref / (seats/dep)_{ref-5} - 1` on annual sums |
| pax_per_capita | bts_socrata,census_cbsa | 12m | `annual_enplanements(ref) / catchment.population[latest year ≤ ref]` |
| pct_arr_delay_gt15 | bts_otp | 12m,3y | Σ`arr_late15` / Σ`arrivals` over window |
| avg_dep_delay_min | bts_otp | 12m,3y | Σ`dep_delay_min_sum` / Σ`dep_count` |
| nas_delay_share | bts_delay_cause | 12m,3y,5y,10y | Σ`nas_delay_min` / Σ`total_delay_min` (measures from Delay Cause) |
| taxi_out_p80_min | bts_otp | 12m | p80 from `otp_taxi_hist` over window (cumulative bucket count ≥ 0.8·N) |
| ops_per_runway | faa_taf,ourairports | 12m | `taf_history.ops_total[latest actual year ≤ ref] / count(runways where not closed)` |
| npias_capacity_label | faa_npias | forecast | `npias.capacity_label` (0 none,1 congested,2 constrained_2033,3 constrained_2028,4 severe_2033) from curated lists |
| peak_hour_ops_ratio | bts_otp,curated | 12m | median(`otp_peak.p95_hourly_ops` over window) / `curated_inputs.declared_rate_vmc`; flag `otp_reporting_carriers_only` |
| pax_per_gate | bts_socrata,curated | 12m | `2 × annual_enplanements(ref) / gates` (total pax ≈ 2× enplanements; flag `total_pax_estimated_2x`) |
| deps_per_gate_day | bts_t100,curated | 12m | `Σ routes_month.departures (window, seats>0) / gates / 365` |
| imc_capacity_ratio | curated | static | `declared_rate_imc / declared_rate_vmc` |
| slot_or_cap_flag | curated | static | `curated_inputs.slot_or_cap_flag` |
| carrier_hhi | bts_t100 | 12m,5y | Σ(share_c²)×10000, share by passengers over window (routes_month grouped by carrier) |
| top_carrier_share | bts_t100 | 12m,5y | max share |
| intl_pax_share | bts_socrata | 12m,3y,5y,10y | Σ`intl_out_passengers` / Σ`total_passengers` |
| longhaul_dep_share | bts_t100 | 12m,5y | Σdepartures(distance≥1500, seats>0) / Σdepartures(seats>0) |
| route_count_nonstop | bts_t100 | 12m,5y | count distinct dest with departures>0 |
| competing_seats_100mi | bts_t100,ourairports | 12m | Σ over other `commercial` airports within 100 mi (haversine) of their trailing-12m Σseats |
| od_share | bts_db1b | 12m | `od_pax/total_pax` latest year (absent if adapter did not land) |
| cbsa_population | census_cbsa | 12m | latest `catchment.population` ≤ ref |
| cbsa_pop_cagr_5y | census_cbsa | 5y | cagr over 5 years of population |
| msa_gdp_per_capita | bea_msa | 12m | `gdp_real_usd / population` latest common year |
| msa_gdp_cagr_5y | bea_msa | 5y | cagr of `gdp_real_usd` |
| npias_dev_per_enpl | faa_npias | forecast | `dev_estimate_usd / npias.enplanements` |
| aip_per_enpl_10y | faa_aip | 10y | Σ`amount_usd` for fy in (ref-9..ref) / annual_enplanements(ref) |
| cpe_usd | faa_cats | 12m | latest fy ≤ ref `cpe_usd` |
| nonaero_rev_per_enpl | faa_cats | 12m | `nonaero_revenue_usd / enplanements` (Form 127) latest fy |
Series: for each function, run for `ref_year in range(2016, latest_year+1)`; the `ref_year == latest_year` row is also written with `ref_year = 9999` ("current"). `assert_registry_covered()` fails if any tier A/B id lacks a function (od_share allowed to yield 0 rows).
