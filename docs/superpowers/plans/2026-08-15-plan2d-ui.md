# Plan 2d — Streamlit multi-chat UI + CLI harness (`ui/`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Streamlit chat app (multiple persisted conversations, sidebar with provider status / data vintages / defaults / sample questions, faithful rendering of the fixed `Answer` structure, loud LLM errors) and a non-interactive CLI harness — both driven by the `App` object from `airport_agent.agent`, testable offline with a fake `App`.

**Architecture:** `ui/` imports only `airport_agent.contracts` and (lazily) `airport_agent.agent`. `render.py` turns an `Answer` into Streamlit widgets in the fixed order; `textfmt.py` turns it into plain text/JSON for the CLI; `bootstrap.py` obtains the `App` (real via `airport_agent.agent.build_app()`, or a fake via env var for tests); `streamlit_app.py` composes sidebar + chat; `cli.py` is `python -m airport_agent.ui.cli`.

**Tech Stack:** Python 3.12, Streamlit ≥1.38 (`streamlit.testing.v1.AppTest` for smoke tests), pydantic v2, pytest.

**Spec:** `docs/design/04-ui.md`; `docs/design/03-agent-architecture.md` (§Presentation & transparency, §Failure policy, §Answer synthesis); frozen `src/airport_agent/contracts/conversation.py` (`Answer`, `Plan`, `Table`, `Citation`, `ToolCallTrace`, `ChatMessage`, `SessionState`), `contracts/llm.py` (`LLMError`), `contracts/models.py` (`SourceVintage`, `MetricSpec`).

## Global Constraints
- **FROZEN SURFACE:** `src/airport_agent/contracts/**` and `config/metrics.yaml` MUST NOT change (tag `contracts-v1`). Reviewers git-verify. Any need → STOP, `DECISION NEEDED`.
- **Ownership:** only `src/airport_agent/ui/**` and `tests/ui/**`. Never touch `agent/`, `data/`, `scoring/`, `llm/`, `pyproject.toml`, `tests/fakes.py`. In this worktree `airport_agent.agent` is EMPTY — the app must never import it at module import time (lazy import inside `bootstrap.get_app()`); tests always inject the fake App.
- **Layering:** `ui/` imports only `airport_agent.contracts` and `airport_agent.agent` (lazy). `PYTHONIOENCODING=utf-8 uv run lint-imports` keeps 4 contracts.
- **The UI never re-interprets, recomputes or reformats numbers beyond display** (design 04): table cells are shown as delivered; no rounding that hides precision (use `st.dataframe` default formatting; CLI prints `repr`-faithful values).
- **Fixed render order (contract docstring on `Answer`):** plan_line → headline → evidence_tables → analyst_view → agreement_line → assumptions + uncertainty_notes → follow_ups → tool_trace. Assumptions & uncertainty expander is **open by default on analytical answers** (`plan.intent == "analytical"`), collapsed otherwise. Never omit the assumptions block.
- **Errors:** `LLMError` ⇒ `st.error(str(e))` verbatim (message already actionable) — no partial answers; any other exception ⇒ `st.error(f"{type(e).__name__}: {e}")` plus a hint to check `data/snapshot`/config. CLI exits 1 with the same text on stderr.
- **No caching of LLM outputs** in the UI (no `st.cache_data` around `answer`). `st.cache_resource` is allowed only for the `App` object itself.
- **Interface consumed from plan 2c (must match exactly):**
  ```python
  app.answer(message: str, state: SessionState, *, defaults: dict[str, str] | None = None,
             on_plan: Callable[[Plan], None] | None = None) -> Answer      # mutates + saves state; raises LLMError
  app.sessions.list() -> list[SessionState]; .new(title="New chat") -> SessionState; .load(id); .save(state); .delete(id); .rename(id, title)
  app.data.source_vintages() -> list[SourceVintage]; app.data.describe_metrics() -> list[MetricSpec]
  app.provider_status() -> list[dict[str, str]]   # keys name, model, status, detail
  app.sample_questions() -> list[str]
  airport_agent.agent.build_app() -> App          # lazy import in bootstrap only
  ```
  Defaults keys passed by the UI: `"horizon"`, `"scoring_preset"`, `"peer_group"`.

**Interfaces — Produces:**
- `tests/ui/fake_app.py`: `make_answer(kind: Literal["informational","rank","compare","diagnose"]) -> Answer` (canned; numbers include `12.9`/`13.9` for compare, source `bts_otp` vintage `2026-04`; `Plan.intent` "informational" or "analytical"); `FakeSessions` (in-memory dict, same method names as `SessionStore`); `FakeData` with `source_vintages()` (two `SourceVintage`s) and `describe_metrics()` (`load_registry()`); `FakeApp(sessions_dir=None)` with `answer(message, state, *, defaults=None, on_plan=None)`: chooses kind by keyword (`"compare"`→compare, `"unmet"`→diagnose, `"long haul"`/`"percentage"`→informational, `"error"`→ raises `LLMError("gemini", 429, "quota exceeded")`, else rank), calls `on_plan(plan)` first, appends user+assistant `ChatMessage`s to `state`, records `defaults` in `self.last_defaults`, saves via `self.sessions.save(state)`; `provider_status()` → `[{"name":"gemini","model":"gemini/fake","status":"configured","detail":"fake"}]`; `sample_questions()` → the four; `make_app() -> FakeApp` (module-level factory used through the env var).
- `bootstrap.get_app() -> Any`: if `os.environ.get("AIRPORT_AGENT_APP_FACTORY")` = `"pkg.mod:callable"` → import and call it; else `from airport_agent.agent import build_app; return build_app()`.
- `textfmt.answer_to_text(a: Answer) -> str`: sections in the fixed order with headers `PLAN:`, `HEADLINE:`, one block per table (`title`, then a monospace grid: header row + rows, `None` printed as `-`), `ANALYST VIEW:` (if any), `AGREEMENT:` (if any), `ASSUMPTIONS:` bullets, `UNCERTAINTY:` bullets, `SOURCES:` `source_id (vintage)`, `FOLLOW-UPS:` bullets, `TOOL TRACE:` `tool args rows provider latency note`. `answer_to_json(a) -> str` = `a.model_dump_json(indent=1)`.
- `cli.main(argv: list[str] | None = None) -> int`: args `question`, `--session ID` (load or, if unknown, create with that id? — no: unknown id → create new via `sessions.new()` and print its id to stderr), `--json`, `--horizon`, `--preset`, `--peer-group` (defaults dict); prints text/JSON to stdout; on `LLMError` prints `str(e)` to stderr and returns 1; other exceptions → `f"{type(e).__name__}: {e}"` to stderr, return 2. `if __name__ == "__main__": raise SystemExit(main())`.

### Task 2: Answer rendering (`render.py`) + sidebar (`sidebar.py`)

**Files:** Create `src/airport_agent/ui/render.py`, `src/airport_agent/ui/sidebar.py`, `tests/ui/test_render.py`.

**Interfaces — Produces:**
- `render.table_df(table: Table) -> pandas.DataFrame` (columns as given; `None` kept as `None`); `render.column_help(columns: list[str], specs_by_id: dict[str, MetricSpec]) -> dict[str, st.column_config.Column]` (tooltip = `MetricSpec.definition` when a column name or a cell metric id matches a spec id; else none); `render.assumptions_expanded(answer: Answer) -> bool` (`answer.plan.intent == "analytical"`); `render.render_plan_line(plan_line: str)` (`st.caption`); `render.render_answer(answer: Answer, specs_by_id, *, key: str, on_followup: Callable[[str], None] | None = None)` — in fixed order: caption plan line; `st.markdown(f"**{headline}**")`; for each table `st.markdown(f"*{title}*")` + `st.dataframe(df, column_config=…, hide_index=True)` + footnotes as captions (a table whose title starts with `"Evidence"` or `"More"` beyond the first two tables goes inside a `st.expander("More metrics")` — the Concierge's hidden reason is already in `uncertainty_notes`); analyst view `st.markdown` under `st.subheader("Analyst view")` if present; agreement line `st.info(...)` if present; `st.expander("Assumptions & uncertainty", expanded=assumptions_expanded(answer))` with two bullet lists (always rendered, even if empty → "none stated"); citations as a caption line `Sources: id (vintage), …`; follow-up chips = `st.button(text, key=f"{key}-fu-{i}")` calling `on_followup(text)`; `st.expander("Show work")` with a dataframe of the tool trace (tool, args (json), rows, provider, latency_ms, note); `render.render_error(exc: BaseException)` → `st.error(str(exc))` for `LLMError`, else `st.error(f"{type(exc).__name__}: {exc}")` + `st.caption("Check the data snapshot (data/snapshot/airports.duckdb), config/, and .env.")`.
- `sidebar.render_sidebar(app, ss: dict) -> None` where `ss = st.session_state`; sections in order: **Conversations** (`st.button("New chat")` → `app.sessions.new()` and select it; `st.radio` over `[s.title]` of `app.sessions.list()` selecting `ss["session_id"]`; `st.text_input("Rename")` + `st.button("Rename")`; `st.button("Delete")` deletes current and selects the newest remaining or creates one), **Provider** (`app.provider_status()` rows as `st.markdown(f"{name} · {model} · **{status}**")` + caption detail), **Data vintages** (`app.data.source_vintages()` → dataframe source_id/period_end/fetched_at + a caption "staleness hint: refresh with `python -m airport_agent.data refresh --check`"), **Defaults for this chat** (`st.selectbox` horizon [12m,3y,5y,10y] default 5y; preset [balanced, terminal_expansion, congestion_relief, market_entry] default balanced; peer group [hub_class, region, all] default hub_class) stored in `ss["defaults"]`, **Sample questions** (`st.button` per `app.sample_questions()` → sets `ss["pending_input"]`), and a link/caption "Design: docs/DESIGN.md".

### Task 3: Streamlit app + smoke tests

**Files:** Create `src/airport_agent/ui/streamlit_app.py`, `tests/ui/test_streamlit_smoke.py`.

**Behaviour of `streamlit_app.py`:** `st.set_page_config(page_title="Airport Investment Intelligence Agent", layout="wide")`; `app = st.cache_resource(get_app)()` wrapped in try/except → `render_error` and `st.stop()` on failure; init `ss["session_id"]` = newest session or `app.sessions.new().session_id`; `render_sidebar(app, ss)`; `state = app.sessions.load(ss["session_id"])`; `specs_by_id = registry_by_id(app.data.describe_metrics())`; render history: for each `ChatMessage` in `state.messages`: `st.chat_message(role)`; user → `st.markdown(content)`; assistant with `answer` → `render_answer(answer, specs_by_id, key=f"m{i}", on_followup=_set_pending)`; assistant without answer → markdown. Input: `prompt = ss.pop("pending_input", None) or st.chat_input("Ask about US airports…")`; when prompt: echo user message; inside `st.chat_message("assistant")`: `placeholder = st.empty()`; call `app.answer(prompt, state, defaults=ss.get("defaults"), on_plan=lambda p: placeholder.caption("Plan: " + Planner-free summary))` — the plan line text: `f"How I'm approaching this: {p.intent} · engines: {', '.join(p.engines) or 'none'} · {p.presentation_notes[:80]}"` (the final `Answer.plan_line` replaces it after the call); on `LLMError`/Exception → `render_error(e)`; on success `render_answer(...)` and `st.rerun()` is NOT needed (state already saved) — but to refresh the sidebar title call `st.rerun()` once after the first answer in a chat (title changed from "New chat").
