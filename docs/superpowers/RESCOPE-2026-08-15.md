## Process changes (no scope loss; apply immediately)
1. Reviewers: **sonnet**, diff-only, no gate re-runs, no empirical probes, report ≤ 25 lines, only Critical/Important
   findings block. Opus reviewer only for the one final whole-branch review per workstream.
2. **Fix rounds only for Critical/Important.** Everything else → ledger `minor (deferred)`, triaged at the final review.
3. Small fix diffs re-reviewed by the controller by inspection (no dispatch).
4. Batch adjacent tasks into one dispatch (implementer writes both, one review).
5. Implementers stay sonnet unless the task needs source-format verification (adapters).
